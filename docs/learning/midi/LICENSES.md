All files from the Mutopia Project (https://www.mutopiaproject.org), downloaded unmodified. Mutopia lists the licence per piece on its piece-info page; all four below say "Copyright: Public Domain" (checked 2026-10-27). Licence terms: https://www.mutopiaproject.org/legal.html

Ranges are sounding MIDI note ranges. A 37-key keyboard spans 36 semitones (e.g. C3-C6), so all fit if you transpose by octave as needed. Several have a bass/second track you can mute.
